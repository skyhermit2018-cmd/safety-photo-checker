          • API 키는 이 브라우저의 localStorage에만 저장됩니다. 앱 운영자는 키를 볼 수 없습니다.
          • 판독할 때 사진과 프롬프트가 선택한 제공사(Google 또는 OpenAI)로 브라우저에서 직접 전송됩니다.

          키 발급 (1분)

          1. Google Gemini: aistudio.google.com/app/apikey → Google 계정으로 로그인 → API 키 만들기 → AIza… 또는 AQ.… 키 복사
